# Materials

The renderer supports nine NDF models: GGX, GTR, Beckmann, Gauss, Blinn-Phong, Ashikhmin-Shirley, Schlick, Sawicki, and PRISM-generated. New materials use GGX. The Inspector exposes base color, HDR emissive radiance, roughness, model, workflow, dielectric reflectance, alpha mode, double-sided rendering, texture UV selectors, normal scale, occlusion strength, and per-slot UV transforms. Metallic appears only in the metallic-roughness workflow because specular-glossiness shading does not consume it. The GTR gamma control appears only for GTR materials. Dielectric reflectance controls appear only in the metallic-roughness workflow, with either index of refraction or explicit F0 shown according to the selected mode. PRISM payloads and provenance are serialized in material assets and scenes; see [Generated PRISM NDFs](generated-ndf.md).

Direct lights evaluate the selected analytic NDF. Environment lighting uses the GGX split-sum approximation for GGX. GTR and the other analytic models evaluate their selected NDF against the source panorama with a 128-sample importance proposal and the selected-NDF/proposal-PDF ratio. GTR uses its own distribution-matched proposal; the remaining models use an anisotropic GGX proposal mixed with uniform projected-disk samples to cover broader NDF tails. Ashikhmin-Shirley preserves its U/V roughness and tangent orientation in both the NDF and proposal. PRISM retains its generated-distribution integration path. Analytic non-GGX environment lighting costs more texture samples and can show sampling noise around small, bright panorama features; the split-sum GGX path remains the faster approximation. The GGX split-sum LUT and direct lights both use correlated Smith GGX visibility. Other selected distributions still use this shared GGX geometry term, so they are hybrid NDF/visibility models rather than matched Smith masking-shadowing pairs.

Double-sided materials render both triangle orientations and reverse the back-face normal before lighting, including the normal written by the ambient-occlusion prepass. In the specular-glossiness workflow, imported glossiness is converted once to perceptual roughness (`roughness = 1 - glossiness`). Its diffuse input is pre-partitioned by the maximum specular F0 and receives no second Fresnel attenuation in direct or environment lighting. Metallic-roughness materials retain angle-dependent Fresnel reduction in direct diffuse and the roughness-aware diffuse approximation in environment lighting. The environment split-sum specular reconstruction uses the LUT's integrated coefficients as `F0 * A + B`; roughness-aware Fresnel is not substituted for `F0` in that expression.

Primitive materials are stored on their mesh renderer. Imported models can store separate overrides by material slot. Scene saves preserve all material values, including boundary values and each texture transform. Applying an override creates an entity-owned renderer material instance so objects sharing an imported model retain independent settings.

Scene files that contain Legacy lighting data, or material records that omit the historic model field, are rejected with an error naming the material path and asking the author to reauthor it with GGX or GTR. Loading does not rewrite or reinterpret those materials.

## Texture anisotropic filtering

Engine Settings sets the maximum anisotropy to 1x, 2x, 4x, 8x, or 16x (8x by default). Each material texture slot can follow the global cap or request a fixed supported level. The renderer clamps a slot request to the engine maximum. A resulting 1x level keeps the imported minification, magnification, and mip filters; higher levels use anisotropic sampling. Imported texture address modes and generated mip levels are preserved, and changes apply to loaded materials at the next frame boundary.
