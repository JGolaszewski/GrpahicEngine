# Texture mip generation

Imported textures receive a complete CPU generated mip chain before GPU upload. Each destination texel uses an area weighted box filter over its footprint, so odd and non-square source dimensions contribute every texel. Color textures marked sRGB are decoded to linear light for filtering and encoded again for storage. Mip generation receives an explicit channel semantic because alpha is not opacity for every material texture.

Base-color textures use alpha-weighted RGB filtering because alpha stores opacity. Their alpha is averaged independently. Masked base-color textures also scale each generated mip's alpha toward the base image's coverage at the material cutoff. Other color maps, such as emissive textures, filter RGB independently from alpha. Data maps, including metallic-roughness, specular-glossiness, and occlusion, average every channel independently; in particular, specular-glossiness alpha retains its glossiness value without weighting RGB. Material data channels are treated as linear. The semantic is included in the texture resource cache key so a shared image used in different roles receives distinct mip data.

Normal maps are interpreted as signed vectors, area averaged without alpha weighting, normalized, and encoded back to RGB. A degenerate average falls back to the tangent-space +Z normal. Their alpha channel is averaged independently.

For a base-color texture used by a masked material, the mip generator scales each generated level's alpha toward the base image's coverage at the material's alpha cutoff. Coverage is discrete at small mip sizes, so the generator selects the scale with the closest representable covered-texel fraction. Texture semantic and, for masked base color, alpha cutoff are part of the texture resource cache key because they affect generated mip data.

The unit suite checks deterministic mip pixels for invalid and odd-sized images, sRGB color, independent data/color alpha filtering, normal-vector averaging, and masked alpha coverage at every generated level. These CPU tests run without a graphics device. A resource cache regression checks that one source identity requested with different mip semantics gets distinct resources. Rendering comparisons for distant foliage and normal-map detail remain dependent on a suitable D3D11 test environment.
