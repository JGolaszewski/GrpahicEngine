# Core API reference

The API reference is generated by Doxygen from documented public headers in `GraphicEngineCore/modules/`. The first documentation coverage milestone is the Core subproject; Editor and backend APIs are not included in this initial slice.

After running the documentation build, browse the generated <a href="../api/index.html">GraphicEngineCore API reference</a>. The generated reference is copied into the MkDocs site at `api/` and is not checked into source control.

The reference begins with selected runtime result types, asset-management APIs, scene APIs, and rendering interfaces. Add Doxygen comments next to public declarations when documenting a contract, ownership rule, parameter, or failure behavior.
