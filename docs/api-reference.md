# GraphicEngine API reference

The API reference is generated by Doxygen from first-party public headers in `GraphicEngineCore/modules/`, `GraphicEngineEditor/modules/`, and `GraphicEngineBackends/D3D11/include/`. It covers the engine's runtime, scene and ECS, assets, rendering, editor application and panels, editor events and commands, platform integration, and D3D11 window/backend interfaces.

Browse the generated class, namespace, function, and file indexes under **Engine API** in the site navigation. Doxygen XML is converted into Markdown pages as part of the MkDocs build, so the API reference uses the same theme and search as the rest of the site. Generated pages are not checked into source control.

The reference includes API comments alongside declarations in the public headers. Document contracts at the declaration, including ownership and lifetime, parameter meaning, valid states, and failure behavior where those details are part of the interface. Internal implementation headers, vendor code, and test implementation details are excluded from the generated reference.
